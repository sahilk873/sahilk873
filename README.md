# Sahil Kapadia

**Machine learning research in healthcare AI and quantitative finance.**

I build research systems that are reproducible, leakage-controlled, and grounded in evidence, from clinical LLM evaluation and medical imaging to point-in-time financial NLP and market microstructure. I'm most interested in how intelligent systems learn, adapt, and get used in the real world.

### Currently

- **BODHI-MedCalc**: contributing analysis tooling, including per-arm cost and latency accounting, to the [BODHI clinical-LLM project](https://github.com/felipeocampoos/BODHI-Medcalc-NeurIPS)
- **priml**: contributing to [Rekursiv's priml](https://github.com/rekursiv-ai/priml), strongly typed building blocks for A/B testing ML research
- **INVent Lab**: member of the [Viswanath Lab](https://github.com/viswanath-lab) at Emory University

### Selected work: healthcare AI

| Project | What it does |
| :-- | :-- |
| [**MRI_Comparison**](https://github.com/sahilk873/MRI_Comparison) | Reproducible pipeline for a manuscript quantifying the protocol robustness of ADC MRI across 64 mT and 3 T scanners, using deep embeddings and classical radiomics |
| [**eclipse**](https://github.com/sahilk873/eclipse) | LLM-guided evolutionary search that designs triage and intake policies for a simulated emergency-department queue under a safety-first objective |
| [**bohdi-lora**](https://github.com/sahilk873/bohdi-lora) | LoRA fine-tuning that moves epistemic virtues (humility, calibration, abstention) out of a prompt wrapper and into model weights |
| [**MLHC**](https://github.com/sahilk873/MLHC) | Quantifies pulse-oximetry bias across skin tones and tests debiasing and calibration strategies |
| [**MML_LSTM**](https://github.com/sahilk873/MML_LSTM) | Predicts whether drug combinations are indicated or contraindicated for a disease, for polypharmacy and drug repurposing |
| [**DRG-MVP**](https://github.com/sahilk873/DRG-MVP) | Reconstructs inpatient encounters, reconciles documentation against coding and billing, and routes only consequential exceptions to human review |
| [**First-Principles**](https://github.com/sahilk873/First-Principles) | Secure B2B web app for blinded expert review of spine-surgery appropriateness, aggregating scores into a consensus rating |

### Selected work: quantitative research

| Project | What it does |
| :-- | :-- |
| [**edgar-delta**](https://github.com/sahilk873/edgar-delta) | Point-in-time, evidence-grounded detection of corporate claim revisions across 10-K, 10-Q, and 8-K filings |
| [**macro-expectations-engine**](https://github.com/sahilk873/macro-expectations-engine) | Extracts prediction-market-implied macro expectations, measures surprises against realized data, and tests cross-asset reactions |

| [**lob-market-maker**](https://github.com/sahilk873/lob-market-maker) | Limit-order-book market maker and deterministic exchange simulator for microstructure research |
| [**out-of-model-risk-monitor**](https://github.com/sahilk873/out-of-model-risk-monitor) | Flags thematic concentrations and residual-return clusters in equity portfolios that standard factor models miss |
